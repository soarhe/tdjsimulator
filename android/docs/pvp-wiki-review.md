## 已能从资料理解，不必先请用户解释

- [过量治疗](https://wiki.biligame.com/tdj/状态/过量治疗)：治疗量超过目标可恢复血量；不是额外血条。
- [幽寂](https://wiki.biligame.com/tdj/状态/幽寂)：令符合条件的可驱散增益失效，不等同于删除全部增益。
- [安定](https://wiki.biligame.com/tdj/状态/安定)：消耗层数保护可驱散增益，不能直接理解成免疫所有负面效果。
- [正练](https://wiki.biligame.com/tdj/状态/正练)、[逆练](https://wiki.biligame.com/tdj/状态/逆练)：两套会互相清除的叠层状态，关联技能使用顺序。
- [剑痕](https://wiki.biligame.com/tdj/状态/剑痕)：影响特定施加者攻击时的防御，并在叠满后限制部分规避效果；不应无条件改写全局物防。
- [醒剑骨](https://wiki.biligame.com/tdj/状态/醒剑骨)：免死后的条件性生存状态，不应简化为多一条命。
- [伤势](https://wiki.biligame.com/tdj/状态/伤势)：叠层达到条件后结算的机制，存在治疗/非伤害绝学减层，不能当成普通攻击减益。

## 首轮问题 1–8：用户已回答

2026-10-26 已收到回答，详细规则及适用边界见 [需求与规则记录](pvp-requirements.md#2026-10-26-补充规则用户确认)。

| 问题 | 已确认结论 |
|---|---|
| 1. 三类再动 | 再移动仅走位；再行动可操作；再激活恢复可行动资格，等下次己方行动机会 |
| 2. 分身轮次 | 胧梦婳妖分身独立轮次，其他召唤物跟本体；对方无行动机会时己方剩余轮次可连续进行 |
| 3. 范围与连通 | 格为曼哈顿范围，圈为正方形范围；对角不连通 |
| 4. 持续时间 | 再行动/再激活后的行动正常减 Buff 与技能时间，有不减 Buff 的特例；天赋间隔按自身行动计，地形/机关/结界按大回合计 |
| 5. 对战与协攻 | 对战进入战斗画面；天音白菀要求己方先出刀，被先攻不触发 |
| 6. 伤害次数 | 多目标多次、追击计、仅扣盾计；战前固定伤害和闪避不计 |
| 7. 场地与击退 | 地形/机关/领域可共存；清地形机关不等于清领域；地枢连续击退在整体移动结束结算 |
| 8. 免死与毒伤 | 醒剑骨存在期间不能免死；诸葛亮毒区消耗免死或灯后，下次行动结束再结算毒伤 |

仍需逐技能/回放补齐的边界：按技能描述整理不减 Buff 的再行动（用户已举例剑心无邪“踏跃芳丛”）；再移动已确认不扣 Buff/冷却；仍待核对施加状态当次的扣时点、其他技能“每回合”触发上限的特殊说明（波旬欲界已确认按大回合）、战前驱散/护卫/先攻顺序、领域来源消失后的处理、飞行经过毒格。无需重复询问已经确认的通则。

## 后续按角色逐项核对

9. **召唤物与全场计数。** 用户已确认召唤物与分身均参与友方死亡、友方人数统计；女性人数按单位性别判断，无性别算非女。继续查各召唤物性别；属性继承取召唤瞬间还是动态同步仍待确认。
10. **状态等级 / 层数 / 持续时间。** 等级升降到边界如何处理？同名不同等级状态如何覆盖？天音白菀魂链与神佑状态的细表需要继续补读，不能仅据名词推断。
11. **链锁的朝向限制。** 必须每一步靠近施加者，还是只要求最终落点更近？能否绕路及使用传送？
12. **观星和走火入魔。** 观星三类如何判定复合技能/召唤行动？走火入魔的错误目标或方向从哪些合法对象中随机？这些概率/分类边界需实战或明确资料支持。

## 当前不应直接采用的假设

- 所有召唤单位都跟随主人、所有再动都是立即连动。
- 所有 Buff 都在大回合结束扣时长。
- 领域等于可替换地形，毒雾等于敌方技能地形。
- 免死等于复活，所有“死亡”文本都能被免死阻止。
- 所有攻击加成都已显示在常驻面板：已确认当前面板 Buff 不重复加算，但仅对战中生效的条件属性需另行区分。

## 已确认的具体触发上限例子

[波旬欲界](https://wiki.biligame.com/tdj/天赋/波旬欲界)：友方死亡时，已行动结束的波旬尉迟良可获再激活，文本限定该再激活每回合一次。用户已确认：同一大回合首次友方死亡触发后，波旬再次行动结束，此后另一个友方死亡不再触发该来源的再激活；下一大回合重置。这里只限制此天赋来源，其他来源的再激活另算。

### 对状态模型的要求

1. 战前保存己方完整实装、角色养成、魂石三部位及词条、饰品完整版本和套装来源；BP 后准备阶段只开放用户已确认的站位与技能调整。
2. 当前面板数值作为观察结果，已包含的 Buff 和装备增益不再重复加算；模拟未来增益变化仍需底层属性或可解释的修正关系，不能直接把当前面板永久固定。
3. 装备效果拆成条件属性、合法行动约束、事件触发三类；同一件装备可以含多类效果。
4. 每个触发器记录来源、目标、前置条件、时点、次数、冷却、重置单位、随机性和证据。未核验的同时触发顺序标为未知，不自行排定。
5. 对方实装未知时保留可能性；未见触发不等于未装备。关键方案应区分确定可行与依赖“对方没有某效果”的假设。

### 待核验边界与取证顺序

- 沿 Wiki 组件链接核对各套装的部位、职业限制和件数效果，由实装推导激活效果；鸿宇天石已核对，其他套装不直接照搬其职业限制。

### 鸿宇天石：组件与激活规则已核对

用户确认其头部仅铁卫可用、衣装与腰部通用；2026-10-26 逐个读取以下 Wiki 页面，与用户说明一致。三个页面标注更新日期均为 2024-01-11。

| 组件 | 部位与职业 | 单件机制摘要 |
|---|---|---|
| [天石命坠](https://wiki.biligame.com/tdj/天石命坠) | 头部，仅铁卫 | 物攻及气血各加7%；受击对战前比较双方血量百分比，满足条件时造成基于自身双防的固定伤害并随机降低目标一项属性 |
| [天石云佩](https://wiki.biligame.com/tdj/天石云佩) | 衣装，全职业 | 血量至少80%时物防加15%；受击对战中物理免伤加10% |
| [天石符珠](https://wiki.biligame.com/tdj/天石符珠) | 腰部，全职业 | 血量至少80%时法防加15%；受击对战中法术免伤加10% |

两件效果：免疫击退与拉拽；周围3格内其他角色每增加一人，自身双防增加5%，上限20%。描述不是“其他友方”，不能擅自只数友军。

三件额外效果：受到方向性范围技能攻击时，身后直线3格其他友军的免伤及暴击抗性增加20%；血量至少50%时，自身双防增加20%，3格内其他友军获得基于施加者双防之和10%的双防加成。方向、条件作用域及多个来源的叠加仍需核验，不能仅依据断句确定事件顺序。

建模结论：这是指定饰品的组合效果，不是独立附加到任意饰品的选项。依据组件限制，非铁卫也能穿衣装与腰部获得两件效果，因此不能将推拉免疫仅列入铁卫的可能能力。三件配置需要能够佩戴铁卫头部；套装件数与单件效果分别记录。其他套装能否同时激活需依据各自组件槽位检查，不能由本例直接概括。

资料工作原则：先读 Wiki 单件、套装及关联状态页面，只有资料缺失、歧义或与客户端矛盾时再请用户澄清。

### 对下棋模型的影响

- 饰品有再移动、射程、穿越阻挡、清除机关、状态反转、持续时间调整、免疫等机制；只录增减伤无法判断合法走法。
- 四套套装按实际组件与职业槽位推导，不能任意勾选。鸿宇天石衣腰通用，两件推拉免疫不限铁卫；头部仅铁卫。三件与单件效果保留。
- 推拉免疫、传送免疫分开。状态图鉴的传送包括传送、扰动、牵引；辟险描述击退/拉拽。不能用一个“不可位移”布尔值替代全部规则。
- 魂石天、地、荒分别记录套系和实际词条，不默认三枚同魂。原表之外的头狼会影响移动，幽魉影响战后恢复，死魇鬼卒依赖死亡事件。
- 星魂六选一，回响影响基础属性与选择效果，合计等级5/15/30另有基础奖励。来源：[官方星魂介绍](https://tdj.zlongame.com/jx/tdjNotice/20220809/15651.html)。
- 星之晶不仅改变数值，还关联神兵技能等级。来源：[神兵化臻介绍](https://wiki.biligame.com/tdj/神兵化臻系统介绍)。己方应存实际六枚和神兵等级，不以原表上限替代实装。
- 用户确认面板已经包含buff增益。观测面板和配置推导不能重复相加；隐藏条件效果独立建模。

### 明确剩余项

1. 五件缺页饰品的当前客户端文字；目前原表可作为暂用证据。
2. 魂石逐级值、各槽词条范围和星魂逐级值；实际配置直接读取可绕过反推上限的需求。
3. 套装与魂石结算边界：同一次攻击触发多个条件如何叠层、跨血线回血、护卫下选定目标和受击者、多个来源叠加、多目标概率。各套的具体问题保存在openQuestions；文字明确的灵脉化魄每人50%返还概率已补齐，不再列为未知。
4. 括羽、辟眩、魂力、剑意、猎印、无摧·禁疗的状态元数据，未写出的驱散/扩散/偷取保持未知；无摧·禁疗明确不可驱散。
5. 首版己方实际装备、魂石词条、星魂、神兵配置尚未绑定，不能自行假定满配。

这些是待客户端读取或回放验证的边界，不是已完成项。当前不能声称“自动下棋规则已全部补齐”，也没有改动既有H5伤害口径。
